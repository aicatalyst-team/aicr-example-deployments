So lets have a look at the workflow:

You can optionally start by taking a snapshot of an existing cluster to draw a baseline.

The recipe command can run from scratch or to use this snapshot along with other parameters.

The validate command checks that the recipe has been deployed properly.

In the bundle command you choose your deployment platform such as a Argo CD or Helm and a configuration is produced.

Deployment is then performed using these tools independently from AICR. 

The verify command can use cryptographic hashes to check the deployment is running as expected and has not been tampered with.
